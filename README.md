# ❤️ Heart Disease Risk Predictor

A Python + Streamlit machine-learning web app that demonstrates an interactive health-risk prediction interface.

## Important

This is an **educational prototype**, not a medical diagnostic system. The included model uses a built-in classification dataset so the project runs immediately. For a genuine heart-disease project, train and validate the model on a properly licensed heart-disease dataset with matching clinical features.

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local Streamlit URL shown in your terminal.

## GitHub Upload

1. Create a new repository on GitHub, for example `heart-disease-predictor`.
2. Upload these files:
   - `app.py`
   - `requirements.txt`
   - `README.md`
3. Commit the files.

## Deploy as a Web App

For an online demo, use Streamlit Community Cloud:

1. Push the project to GitHub.
2. Open Streamlit Community Cloud.
3. Sign in with GitHub.
4. Select **New app**.
5. Choose your repository and branch.
6. Set the main file to `app.py`.
7. Deploy.

The `requirements.txt` file tells the deployment service which Python packages to install.
